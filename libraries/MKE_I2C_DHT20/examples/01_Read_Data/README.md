# 01_Read_Data

🇻🇳 **Tiếng Việt:**
Ví dụ này hướng dẫn cách đọc dữ liệu nhiệt độ và độ ẩm từ cảm biến MKE I2C DHT20.

**Kết nối phần cứng:**
- SDA -> I2C SDA
- SCL -> I2C SCL
- VDD -> 3.3V / 5V
- GND -> GND

🇬🇧 **English:**
This example demonstrates how to read the temperature and humidity data from the MKE I2C DHT20 sensor.

**Hardware Connection:**
- SDA -> I2C SDA
- SCL -> I2C SCL
- VDD -> 3.3V / 5V
- GND -> GND
